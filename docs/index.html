AI VIDEO / PRE-PUBLISH GATE

AI 内容
发布前检查

把素材来源、原创贡献、事实、画音重构、披露与人工终审串成一条可追溯链路。每个问题只产生三种结果：通过、返工或阻止发布。

使用方法：从 01 开始逐项确认。任何一项出现 BLOCK，立即停止发布；出现 REWORK，则回到对应节点修正后重新检查。

  • PASS进入下一个检查点
  • REWORK返工后重新进入流程
  • BLOCK停止发布并补齐证据
10 GATES / ONE AUDIT TRAIL

从“有权使用”到“可以发布”

这套流程评估的是可验证的创作与发布风险，不用文件哈希变化、删除水印或轻微滤镜代替原创贡献。

  1. Source gate

    素材来源与授权

    保存原创拍摄证明，或记录版权、肖像、声音、商用范围与有效期。

    BLOCK IF来源不明、无权使用，或授权不覆盖当前平台与地区。
  2. Intent gate

    定义新的创作目的

    先写清新增观点、信息、叙事结构或评论价值，再开始自动重构。

    REWORK IF目标只是裁切、变色、改速、换封装或降低相似度。
  3. Trace gate

    转写与时间戳溯源

    保存 ASR 原文、时间戳与不确定片段；关键人名、数字和结论必须人工核对。

    REWORK IF关键句无来源、时间点错位，或低置信片段未复核。
  4. Script gate

    脚本实质性重构

    重做视角、开场、信息顺序和表达，同时保留事实边界与来源。

    BLOCK IF捏造事实或冒充当事人。REWORK IF仅做同义词替换，没有改变视角与结构。
  5. Identity gate

    人物、声音与同意

    替换原音轨并校对发音；克隆真实人物的脸或声音前，必须取得明确许可。

    BLOCK IF未经许可模拟私人个体、生成未成年人肖像，或让人物看似说过、做过虚假内容。
  6. Edit gate

    画面创意贡献

    核对镜头选择、重排、构图、字幕、节奏和音画关系是否服务于新的表达。

    REWORK IF输入与输出的主要叙事几乎相同，只剩轻微几何或色彩变化。
  7. Disclosure gate

    AI 与商业披露

    逼真的 AI 生成或显著编辑内容要标注；自有品牌推广与付费合作要选择对应商业披露。

    BLOCK IF应披露却拒绝标注，或商业关系未被说明。
  8. Rights gate

    音乐与素材许可

    逐项确认音乐、字体、图片和第三方片段的地区、平台、用途与期限。

    BLOCK IF无法证明商用许可，或把单一平台音乐授权默认扩展到其他平台。
  9. Format gate

    技术发布预检

    检查 9:16、1080×1920、H.264/AAC、帧率、响度、字幕和界面安全区。

    REWORK IF音画不同步、文字被遮挡、黑边明显，或文件无法完整播放。
  10. Human gate

    人工完整终审

    从头到尾观看成片，复核身份连续、事实、社区安全、目标地区与平台准入、受限品类、广告主张证据、音画同步和披露。

    PASS WHEN证据齐全、全片可播放、所有风险项已有明确负责人确认。
FINAL ROUTING

检查结果不是一个“原创度分数”

01 / PASS

发布

保存最终文件、证据清单、披露选择和审核人，再进入平台发布。

02 / REWORK

定点返工

回到失败节点，只修正对应的脚本、画面、配音或格式问题，再重新走检查。

03 / BLOCK

停止发布

权利、同意、事实或披露存在硬缺口时，不通过换版本或重复上传绕开。

说明：这是 RE:FRAME 的内部发布前质量与风险流程，不是 TikTok 或其他平台的官方评分，也不承诺审核或推荐结果。
